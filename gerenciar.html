Como configurar (uma vez por computador)
  1. No GitHub, abra Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Crie um token só para este repositório, com permissão Contents: Read and write.
  3. Cole o token abaixo. Marque “lembrar” só em computador de uso da equipe.

Depois de publicar, o site e o boletim em PDF se atualizam em cerca de 1 a 2 minutos. Sem token, baixe o arquivo e envie em data/alerta.json no GitHub (Add file → Upload files).
